# kanjo serve

Serves the read-only report on 127.0.0.1. Full page written with the slice docs.

| Option | Default | Values | Meaning |
|---|---|---|---|
| `--port` | `serve.port` from the config (8787) | 0 to 65535 | Port on 127.0.0.1; 0 picks a free port |
| `--data-dir` | `data_dir` from the config | a folder path | Folder holding `kanjo.db` |
